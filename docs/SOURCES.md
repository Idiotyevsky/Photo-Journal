# 文档配图与演示资料

README 的界面截图来自项目当前版本的实际界面。截图使用独立创建的演示相册，不读取、展示或包含使用者的私人照片、音乐、旅行记录及资料数据库。

演示相册中的作品集名称、日期、路线、手记、收藏及镜头和曝光参数为演示配置，不代表照片作者的真实拍摄记录。界面显示的机身型号参考对应照片页面，仅用于说明相册的参数展示能力。白边作品和视频预览通过应用本身的导出接口生成。

## 应用素材

- 希腊主题的海岛、陶器、橄榄枝、回纹、波浪及棕榈叶纹样为项目自行绘制的 SVG 矢量素材，保存在 `ui/assets/greek-*.svg`，无需联网加载。
- 托斯卡纳主题的藤蔓、陶砖花饰、橄榄枝、柏树乡舍及陶罐为项目自行绘制的 SVG 矢量素材，保存在 `ui/assets/tuscan-*.svg`，与已有油画小景共同使用，均在本地加载。
- 京都主题的町屋、青海波、木格、枫叶、纸灯笼及枯山水为项目自行绘制的 SVG 矢量素材，保存在 `ui/assets/kyoto-*.svg`，无需联网加载。
- 欧式街角与意大利油画插画使用项目已有主题素材，说明见 [意大利油画创作说明](../ui/assets/意大利油画创作说明.md) 与 [插画创作说明](../assets/插画创作说明.md)。
- 地理轮廓和离线地名资料见 [矢量地图来源](../ui/maps/vector-CREDITS.md) 与 [地名来源](../ui/maps/countries-CREDITS.md)。
- 内置音乐的作者、原始录音及 CC BY 4.0 署名见 [背景音乐说明](../ui/audio/CREDITS.md)。
- 截图中「晨间 · 示例配乐」为文档演示自行合成的声音，仅用于展示配乐选择；不包含私人曲库文件。
