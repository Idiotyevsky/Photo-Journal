# Photo Journal · 拾光相册 APP

双击本目录的 **拾光相册.exe** 即可打开独立桌面窗口。无需安装 Python，无需打开浏览器，没有账号和云存储。

界面采用暖白与蓝灰配色、衬线标题和简洁的画册排版。作品集封面与照片画廊保留完整构图，彩色水彩手绘地图记录沿途足迹。

## 窗口与全屏

界面左上角仅保留图标，点击可返回相册首页。点击右上角全屏按钮或按 **F11** 进入/退出全屏，**Esc** 可退出全屏；如果正在查看照片或编辑信息，Esc 会先关闭当前弹窗。全屏会隐藏系统标题栏和任务栏，再次切回窗口后恢复。

## 开始收藏照片

在「作品集」中点击「创建作品集」，填写名称、地点和简介；可以先保存空作品集，再添加照片。

打开作品集后，可以批量导入新照片，也可以点击「从已有照片添加」。同一张照片可以属于多个作品集，原图只保存一份。编辑作品集可以修改名称、简介和封面；移出作品集或删除作品集不会删除原图。

## 批量导入与管理

点击「导入照片」，然后选择：

- **批量选择照片**：在文件窗口中按 Ctrl+A 全选，或按住 Ctrl / Shift 多选。
- **导入整个文件夹**：一次选入文件夹中的照片，也可以按文件夹名称创建对应作品集。
- **直接拖入**：把多张图片一起拖进应用窗口。

可以继续添加更多照片，导入时统一选择目标作品集、地点和旅程名称。已经导入过的原图会复用，并加入所选作品集。

浏览照片时点击「批量管理」，可以多选、全选当前结果，并一起加入作品集或从当前作品集移出。

- 支持 JPG、PNG、WebP、GIF、BMP、TIFF，每张不超过 100 MB、8000 万像素。HEIC、RAW 请先导出为 JPG 或 PNG。
- 导入会在本地保存原图副本，不移动或改写原始照片。相同内容的照片自动去重。
- 自动读取 EXIF 拍摄时间、机身、镜头、光圈、快门、ISO、焦距、曝光补偿及已有的 GPS 坐标。RGB 预览保留照片内嵌的 ICC 色彩配置。
- 缺少拍摄时间时使用文件修改时间，并在详情中提示，可手动校正。缺少 GPS 不影响时间整理，地点名称可以批量填写。
- 画廊保留完整构图；点击照片查看大图，键盘左右键切换，Esc 关闭。支持收藏、搜索、排序、编辑信息和下载原图。
- 按时间轴或拍摄地点浏览作品。同名旅程的照片汇成一篇手记，未指定旅程时按月份汇集。
- 手记独立保存；照片重新归类或移除后，已经写下的文字仍可阅读和编辑。
- 点击旅途记忆卡片右下角或手记详情中的垃圾桶图标，可删除这段记忆及文字，照片和作品集仍保留。删除结果会随相册资料保存，重新打开不会自动生成回来。

## 白边作品导出

打开照片后，点击大图右上角的「导出作品」，查看实际生成的「白边作品」预览。照片下方紧凑的经典白条会显示相机标识与拍摄参数；信息取自拍摄资料，缺失项自动省略。

点击「保存图片」下载完整尺寸 JPEG，或点击「返回照片」继续浏览。导出会生成新图片，原图保持不变；原图下载按钮也继续保留。

## 作品集视频导出

打开作品集，点击「导出视频」，即可将其中的照片制作为 MP4：**16:9 · 照片居中 · 柔雾玻璃背景 · 淡入淡出**。画面中央展示带相机标识和拍摄参数的紧凑白边照片，四角呈柔和圆角，四周由同张照片的柔和色彩铺开。照片内部保持清晰，仅在圆角边界外侧做一圈很窄的玻璃过渡。

默认使用 1080p、每张停留 5 秒，按拍摄时间由早及晚排列；也可选择 720p、调整停留时间或倒序播放。配乐只从自己导入的音乐中选择，可试听、调节音量，也可选择无配乐；没有音乐时，可前往「设置 → 背景音乐」导入。

弹窗中显示实际生成的画面预览，开始导出后可查看进度或取消。导出期间可以关闭弹窗继续浏览，相册保持打开即可；再次打开该作品集的「导出视频」会恢复进度。一次支持最多 300 张照片、30 分钟视频。

完成后可直接播放成片，并点击「下载 MP4」保存。请及时保存视频；重启相册后不保留尚未下载的成片。下载的视频是独立文件，请与需要保留的资料一同备份。

## 拍摄地点与足迹地图

地点填写分为「国家」和「城市」。进入「拍摄地点」，可以在中国和世界两幅**彩色水彩手绘足迹地图**之间切换。中国地图展示城市之间的路线；世界地图以国家为单位，同一国家的城市合并为一个国家标记，路线中的连续同国地点合并，跨国往返仍可保留。点击国家可以查看该国的照片。照片已有的 GPS 坐标会用于标记；没有 GPS 时，会尝试用填写的拍摄地点匹配本地城市目录，无法匹配的地点可以手动定位。定位在本机完成，无需联网。

点击「编辑足迹」，可以先选择国家，再添加城市或景点（城市选填，也可只记录国家）、调整到访顺序、填写日期和笔记，也可以点选地图位置或关联已有照片的拍摄地点。地图按足迹顺序连接路线，点击关联地点可以查看对应照片。

地图上方的「− / ＋」可在 1–4 倍之间缩放，优先围绕当前选中的地点放大；「复位」恢复全图。也可以按住 Ctrl 滚动鼠标，以指针位置缩放。放大后按住地图拖动，中国和世界各自记住本次会话的视角；编辑足迹时也可放大后点选精确位置。

地图使用 Natural Earth 地理轮廓绘制为彩色手绘风格的矢量图，国家、省区轮廓与装饰在放大时保持清晰。路线粗细、方向箭头、地点圆点和文字保持合适的屏幕大小，随缩放和窗口变化重新排布。地点定位结合照片 GPS 与离线 GeoNames 地名数据，地图来源与许可见 [地图说明](ui/maps/vector-CREDITS.md)。手动保存的足迹与照片独立保留，移除照片或删除作品集不会删除这些足迹。

## 外观设置

点击右上角齿轮「设置」，可在两种主题之间切换，选择会自动保存，下次打开仍然生效：

- **经典**：现有的暖白与蓝灰旅行画册。
- **意大利油画**：暖象牙底色、陶土与橄榄配色、托斯卡纳厚涂油画小景。摄影作品本身的颜色保持原样。

## 背景音乐

打开相册时默认保持安静。点击音符按钮随机播放舒缓纯音乐，再点一次即可静音；曲目结束后会继续随机播放。音乐保存在本机，可以离线收听。

在「设置 → 背景音乐」中点击「导入音频」，可以一次选择多首 MP3、WAV、M4A、AAC、OGG 或 FLAC，每首不超过 100 MB。导入后自动复制到相册资料目录，重复文件不会复制两份。可直接修改曲名、试听、调整音量，勾选的曲目参与随机播放。试听一首后会停止；关闭设置也会停止试听。内置音乐可以停用，自行导入的音乐可以从曲库移除，原始文件不受影响。相同文件重新导入可以恢复已移除的曲目。

内置 Scott Buckley 的九首完整录音：Hymn、The Long Way Home、Castles in the Sky、Reverie、A Kind Of Hope、Sleep（官方纯钢琴版）、Midvinter、Moonlight、Solace，均采用 CC BY 4.0 许可，未作剪辑。官方来源与署名致谢见 [背景音乐说明](ui/audio/CREDITS.md)，也可在相册的「使用与保存说明」中查看。

## 关闭、备份与迁移

点击窗口右上角关闭即可，资料会保留，本地服务也会随窗口关闭。导入进行中请等待完成后再关闭。

个人资料保存在 **拾光相册.exe 旁边的 album-data 文件夹**：

- originals：导入的原图副本，原始字节不变。
- previews：浏览用预览图，自动校正旋转方向。
- music：自行导入的音频副本。
- album.sqlite3：名称、时间、地点、收藏、拍摄参数、作品集、手记、足迹、主题、音量与曲库记录。
- .webview：桌面窗口使用的本地缓存。

在「设置 → 备份与迁移」中点击 **导出完整迁移包**，即可下载包含程序、照片、导入音乐和全部整理资料的 ZIP。照片较多时，准备下载需要一些时间；请等下载完成后再关闭相册。

把 ZIP 带到另一台电脑，完整解压到一个新的可写文件夹，打开其中的「拾光相册」文件夹，双击「拾光相册.exe」即可继续使用。程序与 album-data 应保持在一起。

迁移包结构：

```text
拾光相册/
├── 拾光相册.exe
├── 迁移说明.txt
└── album-data/
    ├── album.sqlite3
    ├── originals/
    ├── previews/
    └── music/
```

内置音乐随程序一同带走，导入的音乐保存在 music 中；作品集、手记、足迹、收藏、照片信息和设置保存在 album.sqlite3 中。

也可以手动备份：关闭应用后，复制整个 album-data 文件夹到其他磁盘。恢复时，在应用关闭的状态下把备份文件夹放回程序旁边。

从相册移除照片只删除相册自己的副本及该照片的编辑记录，最初选择的原始文件不会受到影响。

「使用与保存说明」中的「导出文字资料」仅下载 JSON，包含照片信息、作品集、手记、足迹、设置和曲库记录，不包含照片或音乐，不能代替完整迁移包。换电脑请使用「导出完整迁移包」。

## 本机运行

适用于 64 位 Windows 10/11，需要 Microsoft Edge WebView2 运行时。程序和资料文件夹放在普通可写目录即可，避免放进只读目录。

本地服务只监听本机随机端口，随应用启动和关闭，不向局域网开放，也不上传照片。

## 开发与重新打包

本项目仅提供 Windows 桌面 APP，启动入口为 desktop.py。ui/ 是桌面窗口的内嵌界面资源；server.py 是随窗口启动、关闭的内部本地服务，不提供独立网站启动方式。

其他源码为 photo_export.py（白边图片导出）、video_export.py 与 video_jobs.py（视频制作和任务）。发布程序已经包含 Python、视频编码组件和所需库，日常使用只需双击 EXE。

开发环境需要 Python 3.12，在项目目录运行：

    python -m pip install -r requirements-desktop.txt
    python desktop.py
    python build_desktop.py

打包后的拾光相册.exe 输出在项目根目录。

验证：

    python -m unittest -v test_desktop test_server test_photo_export test_video_api test_video_export
    node --check ui/app.js
    node test_atlas.cjs
    node test_atlas_vector.cjs
    node test_journals.cjs
    node test_fullscreen.cjs
    node test_music.cjs
    node test_video_export.cjs

测试使用临时目录，不修改个人照片。


## 仓库与本地资料

Git 仓库保留桌面 APP 源码、测试、构建脚本、主题插画、离线地图及内置曲目。生成的 EXE、个人 album-data、虚拟环境、构建缓存和开发预览不进入版本管理。

自行导入的照片和音频只保存在个人 album-data 中。请通过 APP 的「导出完整迁移包」备份或迁移个人资料；克隆仓库不会包含这些内容。

第三方素材与组件说明：[地图](ui/maps/CREDITS.md)、[背景音乐](ui/audio/CREDITS.md)、[视频组件](assets/third-party/VIDEO-COMPONENTS.md)。
